# Segment Story Library

Named, reusable proof points per vertical and discovery track, for `email-writer`'s Value-led pattern and `linkedin-dm`'s mirrored pattern to pull from instead of inventing proof language per campaign.

**This file is keyed dynamically off `context/icp.md`** — the verticals below are `context/icp.md`'s current Industry list and the two Discovery Split tracks (Track A / Track B). If `context/icp.md`'s Industry list or Discovery Split changes, update the section headers here to match — do not let this file drift out of sync with the ICP definition it's derived from.

**Refresh trigger:** update this file after every closed-won deal. A stale entry (a story that no longer reflects a live, checkable result) is worse than no entry — if a section below has no real story yet, leave it as `_No story yet — do not fabricate one._` rather than inventing a placeholder metric. `email-writer` and `linkedin-dm` must treat an empty section as "no story available for this segment" and fall back to `offer.md`'s general value prop, never write a fabricated proof point into a campaign.
